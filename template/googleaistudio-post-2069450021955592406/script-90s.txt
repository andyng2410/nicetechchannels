Google vừa ra mắt Interactions API, một chuẩn API mới để tương tác với các Model.
Điểm cần chú ý nằm ở chữ interaction. Trước đây mình hay nghĩ API là gửi prompt rồi nhận câu trả lời. Giờ Google muốn mỗi lần gọi là một phiên làm việc có trạng thái, có bước chạy, có lịch sử để nối tiếp.
Một endpoint, gần như toàn bộ workflow AI. Nó đi từ text generation, streaming, chat nhiều lượt, input đa phương tiện, tạo ảnh, output có cấu trúc, gọi tool, function calling, managed agents, tới background execution. Nói ngắn gọn: dev có một đường chính để dựng app AI nhiều bước, thay vì ghép quá nhiều API rời rạc.
Phần ăn tiền là agent. Interactions API không chỉ gọi model, nó còn cho thấy các step như tool call, function result, hoặc một tác vụ đang chạy nền. Khi app bắt đầu có agent thật, nhìn được tiến trình quan trọng hơn nhiều so với chỉ chờ một cục text trả về.
Google cũng đang đẩy migration. Docs mới nói Interactions API đã được phát hành chính thức từ tháng 6/2026, nghĩa là không còn chỉ là bản preview. generateContent vẫn còn được support, nhưng project Gemini mới thì nên bắt đầu từ Interactions API.
Vậy API này mạnh hơn để làm gì? Rõ nhất là agentic web: những web app mà AI không chỉ trả lời, mà biết search, đọc file, gọi function, trả JSON cho giao diện, rồi chạy tiếp ở background nếu task lâu. Nó cũng hợp với dashboard phân tích tài liệu, support bot gọi API nội bộ, app tạo nội dung nhiều bước, hoặc bất kỳ workflow nào cần thấy rõ từng step.
Nên nếu bạn đang build app với Gemini, đây là thứ cần chú ý. Interactions API không chỉ là endpoint mới, mà là cách Google chuẩn hóa đường đi cho những app AI biết dùng tool, nhớ ngữ cảnh và làm việc nhiều bước như một agent thật.
