# Source analysis: Addy Osmani Loop Engineering

Snapshot checked on 2026-06-18.

## Primary angle

- Main source: Addy Osmani's "Loop Engineering".
- Addy frames the shift as moving from prompting by hand to building the loop that does the prompting for you.
- The article's core structure is five building blocks plus memory: automations, worktrees, skills, connectors, sub-agents, and memory.
- The deck should present Addy as the person who named and framed the concept, not as the only person using it.

## Supporting proof

- WorkOS article: "Key takeaways from Boris Cherny on building Claude Code" gives Boris Cherny as the Claude Code figure used for the second half of the hook.
- The Boris source is used as a directional proof point: people building Claude Code think in systems/loops, not only one-off prompts.
- Anthropic's "Building effective agents" supports the evaluator/checker framing: successful agent systems should use simple composable patterns, clear workflows, and objective verification gates.

## Caveats

- Do not overclaim that loops remove the need for prompts. The deck says prompt remains useful, but becomes raw material inside a larger system.
- Do not imply full autopilot is safe. The script explicitly keeps Addy's warning: faster loops also accelerate mistakes and token spend.
- Boris is supporting context, while Addy is the main source and naming anchor.
