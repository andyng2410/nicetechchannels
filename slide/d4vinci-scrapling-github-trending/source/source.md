## Facts used in the deck

- Scrapling describes itself as an adaptive web scraping framework for a single request through a full-scale crawl.
- Its parser can save an element's properties and use similarity matching to relocate the element after a website layout changes.
- Fetchers include `Fetcher`, `DynamicFetcher`, and `StealthyFetcher`.
- The Spider framework supports concurrent crawling, multiple sessions, pause/resume, proxy rotation, streaming, and optional `robots.txt` compliance.
- The built-in MCP server extracts targeted content before passing it to an AI tool, with the stated goal of reducing token usage.
- README installation commands include `pip install "scrapling[all]"` and `scrapling install`.

## Caveats

- Anti-bot bypass is an author claim from the README, not an independent guarantee for every website.
- README explicitly says users must respect website terms of service, robots.txt files, and privacy laws.
- Trending and star counts are a point-in-time snapshot and may drift after capture.
