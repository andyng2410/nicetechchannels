4. Download router: URL packet enters the `yt-dlp` core and fans out into MP3, playlist, quality, and merged-file outputs.
5. Media extras: central video artifact emits subtitle, thumbnail, and metadata satellites; chapter timeline and SponsorBlock skip marker animate below.
6. Agent workflow: URL to `yt-dlp` to JSON to agent data stream; browser cookie unlocks access; plugin and Python adapters attach at the end.
7. Update and rights: changing website breaks an old binary, nightly branch lights up, final shield reminds viewers to check content rights.

Creative twist: a moving URL packet passes through the deck, changing form from download request to output media, JSON payload, and nightly update signal.
