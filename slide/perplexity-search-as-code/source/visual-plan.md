# Visual Plan

1. Hero: official Perplexity mark over the research OpenGraph image, with a glowing Python route replacing a chain of small search nodes.
2. Old loop: a serial rail of `search -> wait -> search -> wait`, ending in a noisy context tank. Each reveal adds more latency and more red noise.
3. Search as Code: one Python sandbox becomes a router. Queries fan out in parallel, then pass through dedupe, filter, join, and rank modules before a compact context packet exits.
4. Control plane: three-layer stack showing model reasoning, secure sandbox execution, and SDK primitives. A counter scales from hundreds to thousands of retrieval operations.
5. Benchmark proof: a source-proof frame plus two oversized metric comparisons: DSQA `0.871 vs 0.815` and WANDR `2.5x`. Keep the WANDR internal-benchmark label visible.
6. CVE case: security radar scans vendor nodes. A record counter reaches `200+`, accuracy lights to `100%`, and token meter compresses from `288.7K` to `42.9K`.
7. Community: three compact reply lanes around a central code terminal: opportunity, debugging question, and limit warning.
8. Conclusion: final hybrid pipeline `model -> code -> world information`, availability chips for Agent API and Computer, plus a concise benchmark caveat and source.

Creative twist: carry one luminous search packet through the deck. In the old loop it stalls at every round-trip; after Search as Code it splits into parallel packets and recombines into one compact context payload.
