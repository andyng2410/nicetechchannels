# Visual Plan

1. Hero identity: official `bird.fast` mark, kinetic wordmark, agent -> bird -> X rail.
2. Read radar: terminal surface at center; X commands appear as orbiting nodes and feed a collecting agent.
3. Output switch: a terminal payload transforms from human-readable text into JSON blocks and moves into an agent pipeline.
4. Write actions: X compose surface with action orbit; a real CLI success state appears, then an approval gate locks the write path.
5. Install station: Homebrew and npm commands type into one terminal, then a disconnected account plug makes the next setup step visible.
6. Cookie pair: `auth_token` and `ct0` keys orbit a locked X session; broad browser-read path fades while manual env path lights up.
7. DevTools walkthrough: browser frame with Application -> Cookies -> x.com path and two highlighted cookie rows using masked placeholders.
8. Shell persistence: terminal writes masked exports into `~/.zshrc`, reloads config, then `bird whoami` confirms a secondary account. Warning shield stays visible.
9. Caveat and verdict: GraphQL signal connects X to bird, then endpoint break and rate-limit warning appear; GitHub repo becomes private; final lockup says personal experiment, not stable infrastructure.

Creative twist: the same neon signal travels through the deck as an X request, JSON payload, cookie pair and GraphQL line; it becomes unstable on the caveat slide.
