## Khi thêm deck mới đẹp

Nếu tạo được component/animation hay:

1. Ghi lại deck path ở file pattern phù hợp.
2. Mô tả dùng khi nào/không dùng khi nào.
3. Ghi safezone notes nếu component dễ bị tràn đáy.
4. Không copy nguyên CSS dài vào workflow chính.
