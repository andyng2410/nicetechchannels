# Tài liệu NiceTechChannels Template

Điểm vào gọn cho các tài liệu sử dụng, tích hợp đăng video và thư viện visual dành cho agent dựng slide.

## Bắt đầu

- [`HUONG_DAN_SU_DUNG.md`](./HUONG_DAN_SU_DUNG.md): hướng dẫn vận hành từ tạo slide, render giọng đọc đến upload.
- [`../WORKFLOW.md`](../WORKFLOW.md): quy trình bắt buộc khi agent tạo hoặc chỉnh sửa deck.
- [`../AGENTS.md`](../AGENTS.md): quy tắc làm việc áp dụng trong repo.

## Upload video

- [`upload/youtube-api-upload.md`](./upload/youtube-api-upload.md): cấu hình YouTube OAuth và upload.
- [`upload/facebook-api-upload.md`](./upload/facebook-api-upload.md): cấu hình Facebook Page/Reels.
- [`upload/tiktok-api-upload.md`](./upload/tiktok-api-upload.md): hướng triển khai TikTok Content Posting API.

Ảnh minh hoạ cho các tài liệu upload nằm tại [`assets/upload/`](./assets/upload/).

## Dựng slide

- [`../skills/slide-visuals/SKILL.md`](../skills/slide-visuals/SKILL.md): skill visual chính, đã bundle pattern visual và animation.

- [`../script-writing/SCRIPT_RULES.md`](../script-writing/SCRIPT_RULES.md): luật giọng đọc và nhịp câu.

Ảnh của hướng dẫn chính nằm tại [`assets/huong-dan/`](./assets/huong-dan/).
